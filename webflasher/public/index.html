ПЕРЕД ПОДКЛЮЧЕНИЕМ

Три коротких шага.

  1. 01

    Подключи USB

    Нужен кабель с передачей данных и браузер с Web Serial — например Chrome или Edge на компьютере.

  2. 02

    Войди в загрузчик

    Зажми кнопку колеса, нажми RST на плате, затем отпусти кнопки.

  3. 03

    Выбери порт платы

    Закрой другие Serial Monitor и flasher. Выбери USB JTAG/serial или COM-порт T-Embed и дождись проверки.

Совместимость и сохранение данных

Только Lilygo T-Embed CC1101 с ESP32-S3 и 16 МБ flash. Проверка чипа не определяет точную модель платы — её нужно подтвердить самостоятельно.

Обновление принимает только таблицу разделов Bruce 1.15 и пишет приложение с адреса 0x10000. Полный образ пишет также загрузчик, таблицу разделов и NVS, сбрасывая настройки. Сделай резервную копию до прошивки.

Если подключение не получилось

Проверь режим загрузчика, USB-кабель и выбранный порт. Закрой другие программы, использующие COM-порт. При ошибке записи снова войди в загрузчик и повтори установку; успешной считается только запись с совпавшей контрольной суммой.

Физическая прошивка через эту страницу ещё требует проверки на устройстве. При необходимости используй .bin и инструкцию из GitHub Releases.
